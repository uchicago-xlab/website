# archive/

Nothing in this folder is referenced by the site. It is kept so nothing from
the original upload is lost; it can be deleted once everyone is comfortable.
Do not upload this folder to the web host.

| File | Why it is here |
| --- | --- |
| `image-slots.state.json` | The design tool's sidecar that held the team, faculty, and AI-page headshots as embedded data. Those images have been extracted to `images/people/` and each slot now has a `src`, so this 2 MB file is no longer needed. |
| `support.js` | Runtime for the design tool that produced the pages. No page loads it. |
| `DS_Store` | macOS folder metadata that came along with the upload. `.gitignore` now excludes it. |
| `duplicate-fonts/` | Two byte-identical copies of `brand/fonts/XOX-Stencil-v2.otf`, which is the one the pages use. |
| `unused-images/` | Photos and alternate funder-logo versions that no page references. |
